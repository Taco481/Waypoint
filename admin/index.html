GitHub-token instellen

Eénmalig, om automatisch te kunnen publiceren.

Maak een token aan op GitHub: Settings → Developer settings → Fine-grained personal access tokens → Generate new token. Geef repository access “Taco481/Waypoint” en permission Contents: Read and write. Plak de token hieronder. Hij wordt alleen op dit apparaat bewaard.
